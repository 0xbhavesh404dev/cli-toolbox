# 🧰 cli-toolbox

A growing collection of small, dependency-free Python command-line tools.

- Every tool is a **single file** in [`tools/`](tools/) — no frameworks, no third-party packages.
- Each tool ships with **unit tests** in [`tests/`](tests/).
- New tools land through small, focused pull requests.

```bash
python3 tools/dice.py 3d6+2
```

*This project is a learning playground: the goal is to practice clean, small, well-tested Python — one tiny tool at a time.*
